# Dilithium 성능 비교

라이브러리는 GTX 1070에서 batch=10,000, message=32 bytes 조건으로 측정했다.
각 모드에서 Sign 단계의 커널 variant를 자동 튜닝한 뒤 3회 워밍업과 7회 측정
중앙값을 사용했다. 측정 범위는 PQCUDA batch API 전체이며 메모리 할당·전송,
CPU 처리와 GPU 실행을 포함한다.

| 모드 | 연산 | 라이브러리 GTX 1070 (ops/s) |
|---:|---|---:|
| 2 | Gen | 333,267 |
| 2 | Sign | 109,607 |
| 2 | Verify | 251,156 |
| 3 | Gen | 173,777 |
| 3 | Sign | 76,430 |
| 3 | Verify | 160,768 |
| 5 | Gen | 131,894 |
| 5 | Sign | 57,083 |
| 5 | Verify | 97,002 |

원본 `Dilithium 성능평가.png`의 `Our work` 값은 A100/RTX 4090/RTX 3090 Ti에서
측정된 값이다. 따라서 GTX 1070의 라이브러리 값과 직접 비교할 GPU 조건은 표에
없다. 표의 가장 낮은 GPU인 RTX 3090 Ti와 비교해도 라이브러리 값이 낮은 것은
GPU 세대와 성능 차이 때문이다. 예를 들어 Dilithium-2는 표에서 3090 Ti가
Gen 1,418,283, Sign 562,534, Verify 1,484,420 ops/s이다.

같은 GTX 1070에서 기존 cuDilithium 직접 벤치마크의 사전 할당·단일 stream
결과는 각각 다음과 같았다.

| 모드 | Gen | Sign | Verify |
|---:|---:|---:|---:|
| 2 | 387,436 | 148,305 | 373,427 |
| 3 | 188,859 | 95,532 | 232,008 |
| 5 | 141,034 | 72,970 | 137,069 |

라이브러리 값은 기존 직접 벤치마크 대비 Gen 86.0/92.0/93.5%, Sign
73.9/80.0/78.2%, Verify 67.3/69.3/70.8% 수준이다(모드 2/3/5 순서).
이는 라이브러리 API 내부의 메모리 할당·복사와 검증 경로를 포함하기 때문이다.
두 구현 모두 Sign variant는 현재 라이브러리의 자동 튜닝 결과를 사용하지 않고,
기존 직접 벤치마크는 기본 variant를 사용했으므로 Sign 수치는 완전히 동일한
설정 비교가 아니다.

원시 측정값은 `dilithium_library_throughput.csv`에 저장했다.
